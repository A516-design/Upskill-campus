# 📌 Project Title

**Quality Prediction in a Mining Process Using Machine Learning**

---

# 📖 Project Description

This project aims to predict the percentage of silica concentrate in an iron ore flotation plant using Machine Learning. The XGBoost Regressor model is trained on historical process data to predict silica concentration before laboratory testing.

Early prediction enables mining engineers to take proactive actions, improve production quality, reduce operational losses, and support environmental sustainability.

---

# 🎯 Objectives

- Predict % Silica Concentrate accurately.
- Improve mining efficiency.
- Reduce production waste.
- Support predictive decision-making.
- Develop an early warning system.

---

# 📂 Dataset

The dataset contains operational measurements collected from an iron ore flotation plant.

### Features

- Date
- % Iron Feed
- % Silica Feed
- Starch Flow
- Amina Flow
- Ore Pulp Flow
- Ore Pulp pH
- Ore Pulp Density
- Flotation Column Air Flow
- Flotation Column Level
- % Iron Concentrate

### Target Variable

- % Silica Concentrate
